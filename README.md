# 반려 스마트 식물 (Smart Plant)

## 1. 프로젝트 소개
- 프로젝트명: 반려 스마트 식물
- 프로젝트 유형: 전기공학과 캡스톤디자인
- 개발 목적: 센서를 이용하여 식물의 생육 환경을 실시간으로 측정하고, 식물의 상태를 표정과 움직임으로 표현하는 스마트 화분 시스템 개발
- 주요 기능: 온도, 습도, 조도, 토양수분 측정 및 상태 평가, OLED 표정 출력, 사람 감지, 터치 반응, 서보모터 움직임

## 2. 팀원 및 역할
- 오태양: 조도 센서, 토양수분 센서 및 ESP32-S3 시스템 연동
- 팀원 2: 온습도 센서 및 PIR·ToF 사람 감지 시스템 구현
- 팀원 3: OLED 디스플레이 표정 출력 및 터치 센서 제어
- 팀원 4: 서보모터 및 효과음 출력 장치 구현, 전체 시스템 조립

※ 팀원 2~4의 역할은 임시 배정 예시이며 실제 역할에 맞게 수정한다.

## 3. 시스템 구성
### 입력 장치
- 온습도 센서: 주변 온도와 습도 측정
- BH1750 조도 센서: 주변 밝기를 lux 단위로 측정
- 정전식 토양수분 센서: 흙의 수분 상태 측정
- PIR 센서: 사람의 움직임 감지
- ToF 거리 센서: 사람과 화분 사이의 거리 측정
- 터치 센서: 사용자의 접촉 감지

### 제어 장치
- ESP32-S3: 센서 데이터를 수집하고 식물의 상태를 판단하여 출력 장치를 제어

### 출력 장치
- SSD1306 OLED: 식물 상태에 따른 표정 및 정보 표시
- 서보모터: 식물 장식 잎의 움직임 표현
- 효과음 장치: 사용자 상호작용에 따른 소리 출력

### 작동 원리
1. 각 센서에서 환경 데이터를 측정한다.
2. ESP32-S3에서 측정값을 수집하고 분석한다.
3. 온도, 습도, 조도, 토양수분을 기준으로 식물의 상태 점수를 계산한다.
4. 상태 점수에 따라 OLED에 표정을 표시한다.
5. PIR 및 ToF 센서로 사람의 접근을 감지한다.
6. 터치 또는 사람 감지 조건에 따라 표정, 움직임 등의 반응을 제어한다.

## 4. 식물 상태 평가 기준
- 온도: 20점
- 습도: 15점
- 조도: 30점
- 토양수분: 35점
- 총점: 100점

### 총점별 상태
- 85~100점: 최상
- 70~84점: 좋음
- 40~69점: 나쁨
- 0~39점: 매우 나쁨

각 센서의 측정값을 기준으로 점수를 계산하고, 합산 점수에 따라 OLED 표정을 변경한다.

## 5. 사용 부품 및 기술
### 하드웨어
- ESP32-S3 개발보드
- BH1750 조도 센서
- 정전식 토양수분 센서
- 온습도 센서
- PIR 사람 감지 센서
- ToF 거리 센서
- 정전식 터치 센서
- SSD1306 OLED 디스플레이
- 서보모터
- 효과음 출력 장치
- 브레드보드 및 점퍼케이블
- USB 전원 공급 장치

### 소프트웨어
- Arduino IDE
- C/C++ 프로그래밍
- ESP32 보드 지원 패키지
- I2C 통신
- ADC 아날로그 신호 측정
- PWM 서보모터 제어

## 6. 실행 방법
1. ESP32-S3와 센서 및 출력 장치를 회로도에 맞게 연결한다.
2. Arduino IDE를 실행한다.
3. ESP32 보드 지원 패키지를 설치하고 해당 보드를 선택한다.
4. 프로그램에 필요한 센서 및 OLED 라이브러리를 설치한다.
5. USB 데이터 케이블로 ESP32-S3를 컴퓨터에 연결한다.
6. 프로그램 코드를 컴파일하고 보드에 업로드한다.
7. 시리얼 모니터를 통해 센서 측정값을 확인한다.
8. OLED에 식물 상태와 표정이 표시되는지 확인한다.
9. 센서의 측정 환경을 변경하여 상태 점수 및 표정 변화를 확인한다.
10. 사람 감지 및 터치 입력에 따른 출력 장치의 반응을 점검한다.

## 7. 시연 시나리오
1. 시스템에 전원을 공급한다.
2. OLED에 식물의 현재 상태를 표시한다.
3. 조도 및 토양수분 측정값을 확인한다.
4. 식물의 환경 조건을 변화시켜 상태 점수와 표정 변화를 확인한다.
5. PIR 및 ToF 센서로 사람의 접근을 감지한다.
6. 터치 센서를 작동시켜 반응을 확인한다.
7. 서보모터 움직임과 효과음 출력 기능을 점검한다.

※ 위 내용은 시연 계획이며 실제 시연 성공 여부를 의미하지 않는다.

## 8. 트러블슈팅
### 문제 1. OLED 화면 깜빡임
- 증상: 화면 갱신 과정에서 OLED 표시가 깜빡이는 현상
- 원인 분석: 화면 전체를 반복적으로 지우고 다시 출력하는 방식 검토
- 개선 방향: 표시 내용이 변경될 때만 필요한 부분을 갱신하도록 프로그램 구성
- 확인 방법: 센서 측정값 갱신 중 OLED 표시 상태 확인

### 문제 2. 서보모터 반응 지연
- 증상: 입력 조건에 비해 서보모터가 늦게 반응하는 현상
- 원인 분석: 프로그램의 지연 함수, 센서 측정 주기, PWM 설정 및 전원 상태 점검
- 개선 방향: 불필요한 지연 시간을 줄이고 모터 제어 조건을 분리하여 확인
- 확인 방법: 입력 감지 시점과 서보모터 동작 시점 비교

※ 원인 분석과 개선 방향은 점검 항목이며 최종 해결 결과는 검증 후 확정한다.

## 9. 배운 점
- ESP32-S3와 다양한 센서를 연결하고 데이터를 수집하는 방법을 학습하였다.
- I2C 및 ADC를 활용한 센서 데이터 처리 방법을 이해하였다.
- 온도, 습도, 조도, 토양수분에 가중치를 적용하여 식물의 상태를 판단하는 알고리즘을 설계하였다.
- OLED를 활용하여 측정 데이터를 시각적으로 표현하는 방법을 학습하였다.
- 센서 입력과 서보모터 출력의 연동 과정에서 하드웨어와 소프트웨어의 관계를 이해하였다.
- 팀 프로젝트를 통해 역할 분담과 협업의 중요성을 배웠다.

## 10. 프로젝트 기대 효과
- 식물의 환경 상태를 직관적으로 확인할 수 있다.
- 물 부족 및 빛 부족 등의 환경 변화를 쉽게 인식할 수 있다.
- 표정과 움직임을 활용하여 사용자와 식물 사이의 상호작용을 강화할 수 있다.
- 센서, MCU, 출력 장치를 통합하는 전기·전자 시스템 설계 역량을 향상할 수 있다.
