# 반려 스마트 식물 (Smart Plant)

## 1. 프로젝트 소개
- 프로젝트명: 반려 스마트 식물
- 개발 목적: 센서를 이용하여 식물의 환경 상태를 실시간으로 측정하고, 식물의 상태를 표정과 움직임으로 표현하는 시스템 개발

## 2. 팀원 및 역할
- 오태양: 조도 센서, 토양수분 센서 및 시스템 연동
- 팀원 1: 추후 작성
- 팀원 2: 추후 작성
- 팀원 3: 추후 작성

## 3. 시스템 구성
- 입력: 온습도 센서, 조도 센서, 토양수분 센서, PIR 센서, ToF 거리 센서, 터치 센서
- 제어: ESP32-S3
- 출력: OLED 표정 변화, 서보모터 움직임, 효과음
- 작동 흐름: 센서 측정 → ESP32-S3 데이터 처리 → 식물 상태 판단 → OLED·모터·효과음 출력

## 4. 사용 부품 및 기술
- ESP32-S3 개발보드
- BH1750 조도 센서
- 정전식 토양수분 센서
- 온습도 센서
- PIR 사람 감지 센서
- ToF 거리 센서
- 정전식 터치 센서
- SSD1306 OLED 디스플레이
- 서보모터
- Arduino IDE 및 C/C++
- 라이브러리 및 버전: 추후 작성

## 5. 실행 방법
1. ESP32-S3와 각 센서 및 출력 장치를 연결한다.
2. Arduino IDE에서 ESP32-S3 보드를 설정한다.
3. 프로그램 코드를 ESP32-S3에 업로드한다.
4. 전원을 연결하고 센서 측정값을 확인한다.
5. 측정된 환경 상태에 따라 OLED 표정과 출력 장치가 작동하는지 확인한다.

※ 세부 배선도 및 실행 절차는 추후 추가 예정
